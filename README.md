  - 出題アルゴリズム（設計書6章）：ターゲット式＝黒い原石25%（苦手3以上）／未獲得は4ばい。日ごとの4もんの内訳、3日目の3秒以内オーラ
  - 出来栄え★1〜3（ワイルド・グッド・パーフェクト）、黒い原石は完成でにじ色版
  - おとな用：⚙を1秒長押し → [デバッグ] 1日進める／日づけを戻す／にがて・こうぼうの記録リセット
  - テストモード（先生の動作確認用、九九チャレンジと同じしくみ）：こうぼうの上の「v3.0」を3秒以内に5回タッチ → パスワード `9981` → だん別に図かん完成／81こ全部★★★／81こ全部（★1〜3・にじ色まぜ）／さぎょうだいに途中の宝石5こ（黒いげんせき入り）／にがて問題8もん／しょうごうをレジェンドに。最初の操作の前に `supattoWarizan_` の記録を `supattoWarizan_testbak_v1` に自動保存し、「もとの きろくに もどす」で復元（再読みこみ）。保存がある間はバッジが赤く「🧪 テスト中」
- 決めた仕様（理由も一言）：
  - v2の ほうせきばこ（÷1ルビー…、次の日以降の正解で育つ）は こうぼうに置きかえた（同じ式に宝石が2つあると混乱する）。v2の `gems` データは消さずに残し、使わない
  - はっくつを いくつでも できるようにした（育てる数を こどもが えらべるように）。1日目を とちゅうで やめても 同じ げんせきが出る（黒い げんせきの やりなおし よけ）。とちゅうの宝石と 同じ式は 新しく ほらない
  - こうぼうの4もんは まちがえても終わらない（とっくんと同じヒント）。1回めの答えだけ★と苦手スコアに使う
  - 苦手度スコアは設計書の値（誤答+5・5秒以上+2・3秒以内−2）に統一。v2のスコアは2.5倍して引きつぐ（`weakV`=2）
  - ★の計算：4日間の「1回でせいかい」数（16満点）＋平均タイム（3秒未満+2・5秒未満+1）＋オーラ+1。17以上★3、13以上★2
