# スパッと！わり算マスター

小学3年「わり算」（九九の逆算・暗算）の4択タイムアタックアプリ。`index.html` 1ファイルで、インターネットがなくても動きます。

# 【スパッと！わり算マスター】引き継ぎメモ（2026-11-17）
- 対象・単元：3年「わり算」（九九の逆算・暗算）
- できていること：
  - 3モード（ぜんぶ／やさしい 2〜5／むずかしい 6〜9）、ひっかけ入りの4択、10問タイムアタック、ゴースト対戦、コンボ・フィーバー、ブロック分割演出、Web Audioの効果音、称号、キーボード1〜4
  - 苦手スコア（誤答+2・3.5秒以上+1・3.5秒未満−1）と、苦手問題の40%優先出題
  - v2.0：1問ミスで終了／にがて とっくん（ミスしても続く、苦手が2問以下なら1問おきにほかの問題をまぜる）／宝石81こ（げんせき→カット→ピカピカ→アクセサリー、ミスでひび）。アクセサリーは答えごとに9種類／ほうせきばこ／めくりカード／クリアスタンプ
- 決めた仕様（理由も一言）：
  - ミスで終了は3モードだけ、とっくんは続けられる（覚えている途中の子の逃げ道）
  - 宝石が育つのは次の日以降の正解だけ（日をあけても答えられるか確かめる）
  - アクセサリーになるのは「ぜんぶの だん」で3.5秒未満（ほかの段とまざってもすぐ言える）
  - ブロックは割られる数と同じ数まで縮めて表示（数のまとまりを正しく見せる）
  - localStorageのキーは `supattoWarizan_` で始める
- 未解決・次にやること：児童に使ってもらい、ミス終了の厳しさを確かめる。Vercelで公開し、さんすうひろば・kyoin-portal の一覧に追加。今後の候補は docs/ゲーミフィケーション仕様.md の5章
