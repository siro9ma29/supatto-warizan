# スパッと！わり算マスター ゲーミフィケーション仕様書（v2.0 ほうせきの こうざん）

- 元のバージョン：v1.0（4択タイムアタック・10問・まちがえても同じ問題に答え直し・苦手スコア・ゴースト・コンボ／フィーバー・ブロック分割）
- v2.0（2026-11-17）：1問ミスで終了＋にがて とっくん、宝石81こ（ほうせきばこ）、クリアスタンプ

## 0. 決定事項（2026-11-17）
- **出題・判定・苦手スコア・ゴースト・コンボはそのまま**。その上に宝石あつめを重ねる（九九チャレンジと同じ考え方）
- **3つのモード（ぜんぶ／やさしい／むずかしい）は1問ミスで終了**。まちがえたら正しい答えを光らせ、「せいかいは 7。5×7＝35 だね」と出してから結果画面へ
- **「にがて とっくん」モードはミスしても終わらない**（いままでのヒント方式：1回目「5×□＝35 の □は？」、2回目「5の だんを となえよう」）。覚えている途中の子の逃げ道にする
- 世界観は**宝石**：わり算は「わる数1〜9 × 答え1〜9」でちょうど81問。1問＝1こ の宝石。ブロック分割の「スパッ！」と、宝石を切り出すイメージをつなげる
- **育ち方は「次の日以降に正解」**（九九チャレンジと同じ。日をあけても答えられるかを確かめる）。1日に すすめるのは1こにつき1段階まで
- キャラクターや性別を感じさせる絵は使わず、宝石の形と色だけで表す。絵はすべてSVG

## 1. 宝石
- わる数の だんごとに1しゅるい（色と形）
  - ÷1 ルビー（八角形）／÷2 サンストーン（四角）／÷3 トパーズ（三角）／÷4 エメラルド（エメラルドカット）／÷5 アクアマリン（五角形）／÷6 サファイア（六角形）／÷7 アメジスト（マーキス）／÷8 ローズクォーツ（ハート）／÷9 ダイヤモンド
- 段階：？（まだ）→ 🪨 げんせき（★）→ ✂️ カット（★★）→ ✨ ピカピカ（★★★）→ 🌟 かがやき（★★★★・金の光が回る）

| 段階 | 条件 |
|---|---|
| 🪨 げんせき | はじめて正解（どのモードでもよい・その日のうちに） |
| ✂️ カット | げんせきになった**次の日以降**に正解 |
| ✨ ピカピカ | カットになった**次の日以降**に正解 |
| 🌟 かがやき | ピカピカになった**次の日以降**に、**「ぜんぶの だん」で3.5秒未満**で正解（ほかの段とまざっても、すぐ言える） |

| できごと | 条件 |
|---|---|
| 💔 ひび | もっている宝石の問題をまちがえる（段階は消えない）。ひびがある間は育たない |
| 🔧 なおる | ひびの問題に**2回つづけて正解**（プレイをまたいで数える） |
| 👑 そろった | 1つの だんの9こが すべて げんせき以上になると、ほうせきばこの行に👑 |

- 一度まちがえたあと（とっくんで答え直した）の正解では、宝石はすすまない

## 3. とっくん
- 出題：にがてスコア1以上 ＋ ひびのある問題。スコアが高い・ひびがあるほど出やすい（直前と同じ問題は避ける）
- にがて問題が2問以下のときは、1問おきにほかの問題（1〜9のだんからランダム）をまぜる。同じ問題が続くと、思い出さずに答えられてしまうため
- 問題数：にがて問題が2問以下なら6問、3問以上なら問題数×3（最大10問）
- ゴーストなし。タイムは表示するが記録しない
